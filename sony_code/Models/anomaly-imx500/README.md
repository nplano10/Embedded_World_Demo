# Neurala Hifi Vision and Sensing Application

## Content

Files:
 - `neurala_hifi_vns_2.0.0.aot`: Neurala Anomaly HiFi Vision Application, signed and ready for deployment.
 - `neurala_hifi_vns_2.0.0.wasm`: Neurala Anomaly HiFi Vision Application, source of the AoT file.
 - `neurala_hifi_ppl_parameters.json`: PPL Parameter Neurala HiFi, generated from Neurala BrainBuilder configured parameters.
 - `neurala_hifi_output.fbs`: Flatbuffer schema for Neurala Anomaly HiFi to use to parse the output result.
 - `<BrainBuilder_brain_file>.zip`: Zipped Brain files
    - `<Brain>.keras`: Neurala Anomaly HiFi AI model, quantized, ready for upload on Console
    - `deploy.json`: Neurala's brain configuration metadata
    - `labels.txt`: Class names information
    - `packerOut.zip`, `network.fpk`, `network.pkg`: AI models already converted for Console-incompatible IMX500-equipped devices
 - `README.md`

> NOTE: `<BrainBuilder_brain_file>`, `<Brain>` names will match the names provided in BrainBuilder.

## How to use:

1. Import the `keras` model from this brain (found in the `<BrainBuilder_brain_file>.zip` file)
2. Create a configuration for this model
3. Deploy configuration to your camera.

> Refer to Console user manual, the section "3.5.Create model" and "3.5.2.Import button" on how to import the AI model.
>    - [Console user manual (Japanese)][1]
>    - [Console user manual (English)][2]

4. Upload the WASM application `neurala_hifi_vns_2.0.0.aot` to Console
   > Details of this procedure are explained in:
   > - Console user manual for GUI Operation ([jp][1], [en][2])
   > - AITRIOS SDK repository for [scripted Operation][3]
   > In case of issues, use `neurala_hifi_vns_2.0.0.wasm`
5. Create a CommandParameters configuration.
   - Use the `neurala_hifi_ppl_parameters.json` generated by BrainBuilder in `PPLParameter`. See the Neurala knowledge
   base for a [description of the parameters effects][4]. Here is a quick summary:
     * `pixelThreshold` controls how much of the heatmap is showing, increase to reduce the amount of anomalies
     * `imageThreshold` controls if an image is considered an anomaly, increase to detect fewer anomalies
     > NOTE : BrainBuilder configure those thresholds before the Brain conversion happens
     > NOTE2: Do not change "header" field
   - Refer to Console User Manual "Appendix A - A.1. Command Parameter file (JSON) specifications"
   (Console Manual [jp][1], [en][2]) for more information.
6. Retrieve and Parse the output data. Use the flatbuffer file included in your application to generate a package
   parser idiomatic to your programming language
   - Refer to the Neurala knowledge base for a [description of the parameters effects][5]. Here is a quick summary:
     * `width`, `height` will be set to the size of the heatmap. Use it to read the heatmap matrix
     * `heatmap` is a continuous buffer containing the 2D anomaly information. Use it to create your color mask.
     * `anomalyScore` is the global image score. Use it to determine if your image has an Anomaly (high score),
     or not (low score).
   - A sample deserialization python tools is available on the [Neurala AITRIOS tools repository][6]
